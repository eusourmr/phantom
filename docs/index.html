01 / Manifesto

The browser should understand the objective without taking control away from the human.

Independent by design

Own engine, own contracts, incremental standards compatibility.

Meaning beyond pages

Entities, relationships, changes, decisions and actions become first-class concepts.

Memory with consent

Context can persist without turning personal knowledge into telemetry.

AI without privilege

Agents use explicit capabilities and policy gates. High-impact actions remain human-controlled.

Security as architecture

Memory safety, least privilege, typed boundaries, sandboxing and adversarial testing from the start.

Auditability over cleverness

Code should be understandable, replaceable, testable and independently inspectable.

02 / Architecture

03 / Roadmap

Correctness first. Breadth later.

  1. 00
    Foundation

    Workspace, invariants, capabilities, DOM and native shell established.

  2. 01
    Document pipeline

    HTML parsing, URL/origin and document loading foundations are in the engine.

  3. 02
    Style & layout

    CSS cascade, computed style, block/inline layout and Flexbox foundations are implemented.

  4. 03
    Resources & network

    Image decoding, responsive image work, HTTP cache and network isolation foundations are present.

  5. 04
    Hardening

    Compatibility, parser budgets, security boundaries and supply-chain controls are being tightened before the next engine line.

  6. 05+
    Rendering, isolation, events & JavaScript

    Added incrementally only after lower-layer contracts remain stable under adversarial testing.
