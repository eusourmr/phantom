# Phantom 2D-2 — Origin Identity UX

The floating navigation surface remains navigation-only.

A compact transport identity glyph now appears immediately before the address
field only for a committed document or a document error target:

- Lock: HTTPS encrypted transport;
- ShieldAlert: HTTP unencrypted transport.

The hover text shows the canonical typed origin and explicitly describes
transport encryption. It does not claim that an HTTPS website itself is
trustworthy or safe.

No diagnostic counters, status bar or permanent extra toolbar are added.
